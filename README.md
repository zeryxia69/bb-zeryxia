# bb-zeryxia
Script Roblox Blade Ball.

## Loader

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/zeryxia69/bb-zeryxia/main/bb.lua"))()
```

Fallback si GitHub est bloqué :

```lua
loadstring(game:HttpGet("https://cdn.jsdelivr.net/gh/zeryxia69/bb-zeryxia@main/bb.lua"))()
```

Le fichier source principal est `bb.lua`.
